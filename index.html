Ayuda y progreso

Las 51 preguntas y traducciones funcionan sin internet una vez guardado este archivo. El reconocimiento por micrófono puede necesitar internet y permisos del navegador. Para escuchar, Android necesita una voz de inglés disponible en su motor de texto a voz; la primera vez quizá requiera descargarla. El guardado depende de que tu navegador permita almacenamiento local para archivos abiertos desde Descargas.

Elegir voz: el selector «Voz del oficial» muestra las voces inglesas que tu navegador y sistema ofrecen; se elige independientemente en cada dispositivo. La opción «Voz lenta» mantiene la misma voz pero reduce su velocidad. Si solo hay una voz, revisa las voces de inglés disponibles en los ajustes de texto a voz de tu dispositivo.

Micrófono en Samsung: abre Ajustes del teléfono → Aplicaciones → Chrome → Permisos → Micrófono → Permitir mientras se usa la aplicación. Después abre Chrome → ⋮ → Configuración → Configuración de sitios → Micrófono → permitir que los sitios soliciten acceso. Aunque ambos permisos estén activados, Chrome puede bloquear el reconocimiento automático si abriste el archivo .html desde Descargas. Para la función de voz automática, lo más fiable es publicar esta página en una dirección https:// (por ejemplo, GitHub Pages). Alternativa inmediata: «Dictado del teclado» y micrófono de Samsung/Gboard, con idioma inglés.

Navegación: «Ir a pregunta» te lleva directo a la pregunta por su número original (1–51). «Pregunta aleatoria» es un desvío temporal: «Siguiente» retoma la pregunta que tocaba estudiar; «Volver donde iba» regresa exactamente a la pregunta anterior al salto. El programa intenta recordar tu punto de estudio, pero el guardado local depende del navegador.

Privacidad: El botón «Hablar en inglés» pide permiso para usar el micrófono. Según el navegador, el audio puede procesarse en un servicio externo. Esta página no guarda grabaciones de audio ni las envía por su cuenta. El texto reconocido se coloca en el cuadro de respuesta.

La comparación mide similitud con una respuesta de ejemplo. No evalúa acento, pronunciación, reglas DOT ni si la respuesta es correcta para tu situación. Puedes dar una respuesta correcta muy distinta del ejemplo.
